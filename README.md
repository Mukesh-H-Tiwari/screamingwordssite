# Screaming Words website

A responsive static landing page and hosted privacy policy for the Screaming
Words kids' spelling game. The visuals use the game's own character artwork,
screenshots, and sky-blue/candy-color theme.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish

The GitHub Actions workflow in `.github/workflows/pages.yml` deploys the site
when changes are pushed to `main`. Enable GitHub Pages with **GitHub Actions**
as the build and deployment source in the repository settings.

Expected public URLs:

- Landing page: <https://mukesh-h-tiwari.github.io/screamingwordssite/>
- Privacy policy: <https://mukesh-h-tiwari.github.io/screamingwordssite/privacy-policy.html>

The game screenshots and letter illustrations are copied from the Screaming
Words project. Keep the landing-page game details and privacy copy in sync with
the app before publishing changes to the app's data practices or purchases.
